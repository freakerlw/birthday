# 王馨渝的生日卡 · 第二版

参考 OpenMe something-special 的浅蓝生日卡与互动仪式感，使用原站的真实照片和内容重新制作。原站未改动。

## 打开
解压完整目录，双击 index.html。无需安装、构建、网络或服务器。也可将目录内容上传 GitHub Pages 根目录。暗号为 0213，仅作仪式互动，不提供隐私保护。

## 文件
- index.html：中文页面与交互骨架
- styles.css：桌面/手机样式、浅蓝与奶油色视觉、减少动态效果适配
- main.js：暗号、拍立得、蛋糕、蜡烛、36 张相册、放大查看、心愿卡
- content.js：完整保留原有内容数据；照片顺序不变
- assets/photos：原有 36 张照片，未经改动
- robots.txt：禁止搜索索引的提示（不提供访问保护）

日期沿用原站 9 月 14 日，未推断年份。信件正文使用用户最新提供的全文，原礼物地点占位数据不渲染。音乐文件未提供，不加载网络播放器。没有外部字体、脚本、分析或网络依赖。

## 操作
开场数字按钮或键盘输入 0213，也可关闭小卡直接浏览。点击相机依次抽取照片；点击蜡烛许愿，点击或横划蛋糕切开。照片带可触屏横滑、用方向键或章节跳转，照片点击放大，放大后支持左右键与 Escape。心愿卡点击翻面。
